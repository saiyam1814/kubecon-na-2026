Talk summary

Michas Szacillo, a Karmada maintainer at Bloomberg, introduces Karmada as a management system for many Kubernetes clusters across on-premises and cloud environments. He goes over its features and history, and announces that Karmada became a CNCF graduated project on September 3rd.

Watch this if:

you run workloads across many Kubernetes clusters and want a short introduction to Karmada and where the project stands.

Key points from the speaker

  1. 0:59 Michas Szacillo describes Karmada, short for Kubernetes Armada, as a CNCF project that manages Kubernetes clusters on premises and across different cloud providers.
  2. 1:48 He says users get one unified endpoint to deploy workloads to, and Karmada takes care of scheduling them across clusters.
  3. 2:07 He says the Karmada API server is modeled on the Kubernetes API server so existing kubectl workflows fit, and its scheduler places workloads on clusters the way the Kubernetes scheduler places pods on nodes.
  4. 2:53 He describes cross-cluster failover, where cluster health is tracked and applications are moved from one cluster to another, as a way to raise a platform's resiliency.
  5. 3:48 He announces that Karmada is officially a graduated project as of September 3rd, and thanks the people who helped with the adopter interviews.
