Talk summary

Maroon Ayoub and Sean Horgan describe how llm-d serves agentic sessions, which they say read far more input than they generate, by routing to cached context, offloading KV cache and splitting prefill from decode. They show production examples of zero-downtime router rollouts and flow control, and outline the Agentic Inference SIG's plans for session-level orchestration.

Watch this if:

You serve coding agents or other long multi-turn LLM sessions on Kubernetes and care about cache hit rates.

Key points from the speaker

  1. 0:36 Maroon Ayoub says agentic sessions send far more input than output, around a hundred to one, so avoiding recompute unlocks hardware capacity.
  2. 2:46 He describes a production case where prefill compute fell from 16% to 4% while traffic doubled, after fixing how vLLM handled a timestamp Claude Code injects into each turn's system prompt.
  3. 6:26 He explains how the llm-d router balances prefix cache affinity against load-aware routing to avoid hot spots.
  4. 10:44 He shows a production router rollout where the new router loads a state snapshot, takes over traffic and the old one drains with zero errors.
  5. 13:38 Sean Horgan outlines the Agentic Inference SIG's work on orchestrating whole sessions rather than single requests.
