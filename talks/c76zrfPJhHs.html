Talk summary

Sameera Jayasoma argues that developer platforms scatter glue code across portals and pipelines and expose too much underlying complexity to both developers and agents. He presents OpenChoreo as a CNCF project that puts a control plane of higher-level abstractions over existing clusters, observability and workflow tooling, with APIs, MCP servers and a built-in Backstage portal.

Watch this if:

you want a five-minute introduction to OpenChoreo's architecture and its pitch for serving both developers and agents.

Key points from the speaker

  1. 1:19 Sameera says existing developer platforms are hard to maintain because glue code is scattered across portals and pipelines whenever tools are added or replaced.
  2. 2:05 Sameera argues that giving agents unguarded access to underlying tools makes them loop and burn tokens, and that guarded higher-level abstractions with few options work better.
  3. 2:51 Sameera says OpenChoreo was donated to the CNCF last January and reached GA in April after a few years of work behind the scenes.
  4. 3:07 Sameera walks through the architecture of a control plane over data, observability and workflow planes, with an experience plane on top for portal, CLI and agent users.
  5. 4:11 Sameera says agents are also becoming platform workloads that need special treatment, pointing to newer projects such as Agent Sandbox and Agent Substrate.
