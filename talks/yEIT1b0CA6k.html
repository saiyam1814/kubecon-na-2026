Talk summary

Anca Sailer introduces OSCAL, the NIST standard for compliance as code, and OSCAL Compass, the CNCF Sandbox project that provides an SDK and agentic authoring for it. She explains why the agent skills include deterministic code, and shows the project site with demos of digitizing a catalog, upgrading one and generating mappings between regulations.

Watch this if:

you work in a regulated environment and want to see how compliance as code can be authored with agent skills.

Key points from the speaker

  1. 0:30 Anca Sailer describes OSCAL, the Open Security Controls Assessment Language, as a NIST standard for compliance as code, and says moving to continuous compliance needs both standardization and automation.
  2. 1:16 She explains the mapping artifact as a way to reuse existing security implementations when new regulations arrive, naming GDPR, DORA, AI and post-quantum requirements.
  3. 1:54 She says the project turned its original Git action automation into agent skills, and that compliance-to-policy now translates the artifacts into policy as code for engines such as Kyverno, OPA and OpenSCAP.
  4. 2:51 She says the skills include deterministic code so control IDs and policy IDs stay the same between runs and auditors can relate successive audits.
  5. 4:45 She shows the Agentic Authoring page, where she says one command installs the skills into a harness such as OpenCode, and three demos: digitizing a catalog, upgrading a catalog and generating mappings.
