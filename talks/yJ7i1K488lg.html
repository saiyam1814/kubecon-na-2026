Talk summary

Chenyu Zhang and Yan Wang present Harbor as a shared registry for model weights and sandboxed agent images, with different checks for the two supply chains. They demonstrate importing a model from Hugging Face and mounting it in Kubernetes, then discuss declaring an agent's requested permissions alongside its image.

Watch this if:

Watch this if you want to distribute model weights through Harbor and review the permissions a sandboxed agent requests.

Key points from the speaker

  1. 6:45 The speaker explains that ModelPack packages a model as an OCI artifact so a compliant registry can store it without tying distribution to a serving stack.
  2. 12:32 The speaker distinguishes model scanning from ordinary CVE scanning and describes signing model artifacts with Cosign as a separate supply-chain check.
  3. 17:33 The speaker shows a Harbor sync policy for a Hugging Face model, previews the source file list, and inspects the model card and license after the sync.
  4. 19:43 The speaker shows a Kubernetes deployment pointing at Harbor and says Kubernetes mounts the synced model files into the pod.
  5. 22:14 The speaker describes the Docker Sandbox Kit Spec as a declaration attached to the agent image that lists the network destinations, credentials, and paths the agent asks to use.
