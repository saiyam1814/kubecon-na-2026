Talk summary

Divya Mohan, a Longhorn community manager, says version 1.13.0 made the v2 data engine generally available and outlines the next patch and minor releases. She says the project is working toward CNCF graduation and asks production users to add themselves to the adopters file.

Watch this if:

you use Longhorn for Kubernetes storage and want the release plan and how to get involved.

Key points from the speaker

  1. 0:55 Mohan says Longhorn 1.13.0 was released in September 2026 and that the v2 data engine, previously a technical preview, is now generally available.
  2. 2:21 Mohan says version 1.13.1 is due within days and focuses on bug fixes and performance improvements for the 1.13.0 release.
  3. 2:47 Mohan says the next minor release is planned for January 2027 with more v2 data engine feature parity, a Longhorn MCP server, volume group backups, and IP stack and dual-stack configuration.
  4. 3:18 Mohan says the project is moving toward CNCF graduation by growing and diversifying its maintainer pool and discussing a governance structure that splits the project into focused areas.
  5. 4:14 Mohan asks anyone running Longhorn in production to add their name to the adopters file through a pull request, and offers help with that at the project booth.
