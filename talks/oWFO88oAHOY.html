Talk summary

Kasper Borg Nissen moderates a panel on running agents on cloud native platforms, with panelists speaking from end user, security, inference and observability backgrounds. They discuss who owns agent infrastructure, treating agent workloads as untrusted, identity and brokered access, what to instrument, and where teams could start.

Watch this if:

your platform team is being asked to host agents and you want several views on security, identity and observability before you commit to a design.

Key points from the speaker

  1. 7:01 A panelist speaking from the security side says recent kernel vulnerabilities suggest agent workloads should be considered adversarial, and expects sandboxing to stay a cat and mouse game.
  2. 13:04 The moderator says many projects now conform to OpenTelemetry and its GenAI semantics, and a panelist answers that new semantic conventions cannot be added on things that are still unstable.
  3. 17:29 A panelist says identity needs rethinking for agents, names SPIFFE and SPIRE as existing mechanisms, and says their complexity has kept them from being used everywhere.
  4. 20:39 A panelist describes brokering access: the agent gets an object capability for a specific action, such as reading a repository, instead of holding a token itself.
  5. 30:06 Asked where to start, a panelist recommends picking a pet project to learn how to work with agents hands-on.
