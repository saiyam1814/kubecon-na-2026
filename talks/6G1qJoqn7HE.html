Talk summary

Jason Plumb presents OpenTelemetry Android, which started as Splunk's Android agent, its 1.0 stable agent API and the Kotlin DSL for configuring it. He shows a demo app on an emulator where traces start in the mobile app and continue into a backend service.

Watch this if:

you build mobile apps and want traces that start on the device and continue into your backend.

Key points from the speaker

  1. 2:08 Jason Plumb says OpenTelemetry Android began as Splunk's Android agent, offered to the community in 2023 and accepted as a donated OpenTelemetry project.
  2. 5:06 He argues that many traces start in a user's hand and that mobile instrumentation connects them end to end, from phone to database.
  3. 9:07 He explains what 1.0 means: the Android agent, agent API, instrumentation API and session API are stable, while most individual instrumentations are not yet.
  4. 10:42 He introduces the Kotlin DSL, a type-safe way to configure the OpenTelemetry RUM instance with reasonable defaults.
  5. 20:14 In the demo, an error trace shows the root span from the mobile client and a child span from the backend server, which he points to as stitching from app to backend.
