Talk summary

Lasse Vierow describes why inference bills are hard to attribute, since one request can use 70 tokens and another 7,000, and proposes metering tokens per team at a gateway in front of KServe models. In a live demo on a kind cluster he shows token counts in agentgateway logs, per-team usage, a guardrail blocking a credit card number, a token budget returning 429, and failover to a cloud model.

Watch this if:

you run shared model serving on Kubernetes and want a beginner walkthrough of splitting token spend by team at the gateway.

Key points from the speaker

  1. 2:37 Vierow says a request count does not explain cost because one request could consume 70 tokens and another 7,000.
  2. 5:58 Vierow describes the inference extension's endpoint picker choosing a pod by looking at KV cache, prefix and LoRA adapters instead of round robin.
  3. 10:54 In the demo, Vierow shows gateway logs that now include the model that answered and the input and output token counts.
  4. 12:11 Vierow shows that the mock ML research team sent only three requests but used the most tokens.
  5. 13:11 Vierow shows a team that passes its 60,000 token budget getting 429 responses while another team still gets 200.
