    Flatcar Container Linux: Growing the Cloud Native OS Ecosystem

    Jan Bronicki

    Jan Bronicki, a Flatcar Container Linux maintainer, introduces Flatcar as a declarative, immutable, minimal operating system for running containers. He gives a project update covering its CNCF incubating status, its work toward graduation, new governance and changes to packaging, infrastructure and security automation.

    5 min slot · Level not listed · Lightning Talk

    Kubernetes internals and runtimesCommunity and open source adoption

    Watch this if: you are choosing a container host OS and want a short introduction to Flatcar and its plans.

    1. 0:44 Jan Bronicki frames Flatcar as an operating system as code: declarative, immutable, minimal and container optimized.
    2. 1:21 He explains immutability: the core of the OS such as /usr is read-only and verified at boot, and atomic updates replace the whole core without touching user space.
    3. 1:50 He says the same declarative YAML configuration is meant to run on AWS, Azure, GCP and other providers, and that the project is fully open and community driven.
    4. 2:27 He says Flatcar was the first OS distribution accepted into the CNCF and is at the incubating level, and names Adobe, Giant Swarm, AT&T and Dell among its public users.
    5. 3:12 He says the project is aiming for graduation, redoing its governance with a steering committee and a technical committee, aligning packaging with upstream Gentoo, and adding AI-driven triaging of security issues.
