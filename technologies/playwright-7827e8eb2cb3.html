    Running Secure Agents at Scale

    Carlos Sanchez

    Carlos Sanchez describes how Adobe runs browser workloads for AI agents without running those browsers in the agent pods. He compares Kubernetes sandboxing options and walks through how Adobe uses Agent Sandbox to allocate, reuse, and retire remote Playwright environments.

    30 min slot · Advanced · Session

    AI agents and automationSecurity, identity and policy

    Watch this if: You run AI agents on Kubernetes and want to isolate remote browsers without changing how clients use Playwright.

    1. 3:50 Sanchez describes how single-writer persistent volumes can make rollouts interrupt an agent session while a replacement Kubernetes pod waits for the old one.
    2. 9:27 Sanchez names the sandboxing options he evaluated for Playwright, including Agent Sandbox, OpenShell, and Agent Substrate.
    3. 13:08 Sanchez shows the application design: the agent sends Playwright traffic to a proxy that decides whether to reuse or allocate a browser sandbox.
    4. 16:16 Sanchez explains how the controller uses a template, a warm pool, and a claim to give a caller a sandbox.
    5. 24:20 Sanchez describes keeping three Chromium and Playwright instances warm to reduce the wait when an agent requests a browser.

    Your Quickstart is Broken – AI Agents as Synthetic New Users

    Aman Singh

    Aman Singh describes how the Drasi maintainers use an AI agent as a synthetic new user that follows their tutorials exactly and reports where the docs and the real output differ. He walks through the setup with Dev Containers, GitHub Actions, GitHub Copilot CLI and Playwright, and shows bugs it found in Drasi, Dapr Agents and Radius tutorials.

    5 min slot · Any Level · Lightning Talk

    AI agents and automationPlatform engineering and developer experience

    Watch this if: you maintain a project's tutorials and want them tested automatically the way a new user would follow them.

    1. 0:32 Aman Singh says a broken quickstart could be a user's first and last interaction with a young project like Drasi, which he helps maintain.
    2. 1:15 He describes giving the job to an AI agent acting as a beginner, with one key instruction: do not fix anything, report the gap instead of hiding it.
    3. 2:14 He explains the setup: the tutorial's Dev Container runs in a weekly GitHub Actions workflow with GitHub Copilot CLI and Playwright, and a failing run files a GitHub issue with the evidence.
    4. 3:20 He shows a tutorial where every command succeeded and CI was green, but the output was missing a name because the query read the wrong field.
    5. 4:09 He says the same prompt and workflow, with minimal changes, found gaps in the Dapr Agents and Radius getting started guides.
