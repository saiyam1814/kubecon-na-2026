    Todd Baert

    Baert presents feature flags and telemetry as a way to manage AI rollouts without redeploying the application. He uses a calculator demo to show how he evaluates guardrails and model settings for different groups of users.

    How We Are Enabling Feature Flagging At Scale

    Juan Bernal

    Juan Bernal explains why CVS Health looked for an alternative to expensive vendor plans and limited homegrown feature flagging. He describes how OpenFeature and a self-hosted control plane let his team separate flag management from evaluation.

    30 min slot · Any Level · Session

    Delivery, GitOps and release safety

    Watch this if: You are weighing a self-hosted feature flag platform against vendor tools or ticket-driven workflows.

    1. 1:58 Bernal explains how feature flags separate deployment from release and let teams target a rollout to a specific segment.
    2. 4:53 Bernal explains why his team chose OpenFeature: it offers a common contract for evaluating flags across platforms and backends.
    3. 6:42 Bernal walks through the CVS architecture, where a core API feeds both the management interface and flagd, the service that evaluates the flags.
    4. 7:27 Bernal recalls how an OpenFeature maintainer proposed flagd FlagSets to support configuration at both the application and environment level.
    5. 11:09 In a recorded demo, Bernal shows the Flag Controller interface for organizing teams and applications, defining reusable targeting segments, and creating feature flags.

    OpenFeature Update from the Maintainers

    Jonathan Norris, Todd Baert

    Jonathan Norris and Todd Baert report on OpenFeature's growth in providers and SDK downloads, including vendors that now use OpenFeature as their native SDK. They cover new Dart and C++ SDKs, spec 0.9.0, flagd and OFREP improvements, agent skills for OpenFeature, and governance changes.

    30 min slot · Level not listed · Session

    Delivery, GitOps and release safety

    Watch this if: you use feature flags and want to know what changed in OpenFeature, flagd and OFREP this year.

    1. 2:55 Norris says OpenFeature now has almost 300 providers across 51 vendors and, by his estimate, well over 100 million SDK downloads per quarter.
    2. 3:58 Baert describes vendors such as Datadog, Cloudflare, Google Cloud, Vercel and Dynatrace choosing OpenFeature as their native SDK.
    3. 6:41 Baert lists flagd changes, including fractional bucketing on any context type, disabled flags no longer counted as errors, and later a FIPS 140 mode.
    4. 10:08 Norris explains that OFREP can now send a server-sent events URL so clients refetch flags in real time when configuration changes.
    5. 12:12 Norris presents OpenFeature agent skills, saying evaluations improved Haiku from 59% to 89% and Sonnet from 79% to 94%.

    Sample Smarter, Not Harder (Or Not At All!)

    Reese Lee, Juliano Costa

    Reese Lee and Juliano Costa say sampling at the backend doesn't remove the overhead of generating telemetry in the application. Using the OpenTelemetry Demo, they compare disabling redundant instrumentation with probabilistic, policy-based tail, and adaptive sampling.

    30 min slot · Any Level · Session

    Observability and reliability

    Watch this if: You want to cut tracing overhead and keep visibility into slow, failing, or low-traffic requests.

    1. 8:58 The speakers show how they disabled overlapping HTTP instrumentation in the Node.js frontend so it did not generate spans they did not need.
    2. 11:49 The speakers set the collector to sample ten percent probabilistically and compare spans received by the collector with spans sent to Jaeger.
    3. 15:43 The speakers explain that tail sampling sends complete traces to the collector so it can apply policies before forwarding or dropping them.
    4. 16:49 The speakers show tail-sampling rules that keep errors and requests above a latency threshold rather than relying on a fixed fraction for all traces.
    5. 21:41 The speakers describe how adaptive sampling responds to changes in load so a rare checkout flow is more likely to remain visible during a traffic spike.
