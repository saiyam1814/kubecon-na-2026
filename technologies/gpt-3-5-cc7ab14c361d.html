    Edging Closer to AI Assisted Troubleshooting - AI Assisted Dashboard Analysis

    Vijay Samuel

    Vijay Samuel credits Jing Hu for much of the work on eBay's dashboard analyzer and explains why his team moved away from feeding raw telemetry to a model. He describes how the analyzer computes statistics in code and links its hypotheses back to specific dashboard evidence.

    30 min slot · Any Level · Session

    AI agents and automationObservability and reliability

    Watch this if: You want AI-assisted dashboard triage that keeps the math in code and gives on-call engineers evidence they can verify.

    1. 2:27 Samuel sketches a two-server MCP approach that sends dashboard metadata and raw results to a model, then explains why doing this for every panel can bury important facts in the context window.
    2. 6:08 Samuel describes the design rule he wants on-call engineers to take away: compute the telemetry statistics in code and let the model reason over the results rather than do the arithmetic.
    3. 6:38 Samuel explains how the analyzer links hypotheses to findings and then back to the exact dashboard panel and time range so an engineer can verify them.
    4. 10:02 Samuel walks through fetching dashboard metadata, making a plan, and handing different telemetry types to specialized subagents before combining their findings.
    5. 14:04 Samuel describes a metrics subagent that computes statistics in Go, detects anomalies in Python, and uses Largest Triangle Three Buckets to reduce the points it sends to the model.
