    k0s - CNCF Sandbox Distro Updates

    Prithvi Raj

    Prithvi Raj, a k0s community manager, recaps k0s as a single-binary Kubernetes distribution and k0smotron as its hosted control plane and Cluster API provider. He goes through recent updates such as Windows and RISC-V support, k0smotron 2.0 and k0sctl changes, and says the CNCF incubation application is in process.

    5 min slot · Level not listed · Lightning Talk

    Kubernetes internals and runtimesCommunity and open source adoption

    Watch this if: you run or are considering k0s or k0smotron and want a quick summary of the latest releases.

    1. 0:38 Raj describes k0s as Kubernetes in a single binary with no dependencies, with control plane and worker nodes kept separate so they can run in different places.
    2. 2:01 Raj says the sister project k0smotron provides hosted k0s control planes and acts as a Cluster API provider for managing child clusters from a management cluster.
    3. 3:10 Raj says Windows support became stable in recent releases and that RISC-V support now has CI coverage, though there are no release artifacts for it yet.
    4. 3:53 Raj says k0smotron 2.0 brings a new API version and new storage backends, and can bootstrap Windows worker nodes through Cluster API providers.
    5. 6:00 Raj says the CNCF incubation application is in process, with the technical and governance review starting soon, and asks adopters to make themselves known in Slack.

    What’s New in Kairos, 2026 Edition

    William Rizzo

    William Rizzo, a Kairos maintainer, runs through the past year's releases: Kairos 4.4.0 in a monorepo, the Hadron Linux distribution, the Kairos operator, kubeadm support in the Kubernetes provider, and AuroraBoot. He also describes Cluster API providers for Kairos, which he says let Kamaji hosted control planes use Kairos-managed worker nodes.

    5 min slot · Level not listed · Lightning Talk

    Kubernetes internals and runtimesPlatform engineering and developer experience

    Watch this if: you run Kairos or immutable Linux at the edge and want a quick list of what changed over the past year.

    1. 0:52 William Rizzo says Kairos is now at version 4.4.0 and has moved to a monorepo with one version and one pipeline that builds everything.
    2. 1:29 He describes Hadron Linux as an immutable, minimal distribution built on musl and systemd, and says the work focused on hardening trusted boot, FIPS compliant images and gating releases on vulnerability scans.
    3. 2:40 He says the Kairos operator is a Kubernetes native way to handle day two operations such as draining, cordoning and upgrading nodes, and that it replaces their use of the system upgrade controller.
    4. 3:10 He says version 4.0 of the Kubernetes provider now supports kubeadm in addition to K3s and k0s.
    5. 4:26 He describes the Kairos Cluster API bootstrap and control plane provider, and says kubeadm worker node support means Kamaji hosted control planes can have Kairos-managed workers.
