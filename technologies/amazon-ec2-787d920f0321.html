    Kubernetes The Hard Way - Live

    Lucy Sweet, Sandeep Kanabar

    Lucy Sweet and Sandeep Kanabar build a Kubernetes cluster live, starting each component on local virtual machines. They trace an application from a kubectl request through the API server, the scheduler, and the kubelet to a running container.

    30 min slot · Any Level · Session

    Kubernetes internals and runtimes

    Watch this if: You want to see what changes when each Kubernetes component starts and how those changes turn a pod request into a running container.

    1. 6:54 Kanabar starts etcd and inspects its membership, explaining how the API server uses it to persist cluster state.
    2. 7:58 Kanabar verifies etcd by writing and reading a key, then explains why the API server is the entry point for other control-plane components.
    3. 12:41 Sweet explains reconciliation as observing actual state and taking steps toward the desired state, using a deployment with missing replicas as the example.
    4. 13:55 Sweet distinguishes the controller manager, which runs core controllers, from the scheduler, which chooses a node for a pod.
    5. 17:35 Sweet shows why a pod stays pending until a node joins, then uses crictl to inspect the NGINX container running under containerd.

    No RAG, No Regrets: Letting an LLM Drive 30 EKS Clusters in Production

    Trevor Linton

    Trevor Linton describes how Mastercard built an agent harness to handle repeatable infrastructure work without retrieval-augmented generation. He walks through a cert-manager upgrade and explains how scoped tools, result filtering, token limits, and human approvals fit into the workflow.

    30 min slot · Advanced · Session

    AI agents and automationPlatform engineering and developer experience

    Watch this if: You want to automate routine Kubernetes maintenance while keeping approvals and audit trails visible.

    1. 7:30 Linton says his team deploys its Node.js agent harness as a Kubernetes application and uses PostgreSQL to resume interrupted sessions.
    2. 10:16 Linton shows a cert-manager upgrade run that reads release notes, checks compatibility, proposes changes, and leaves merge and production change approvals to people.
    3. 11:39 Linton opens an audit trace that exposes individual tool calls and lets reviewers inspect the data given to the model.
    4. 16:46 Linton describes projections that filter or aggregate tool results before they enter the model context, using a SQL-like interface.
    5. 18:50 Linton explains how each task gets a hard token budget and iteration cap, with the remaining allowance available to the agent on each loop.

    Platform-First AI Agent Security: Zero-Trust Patterns for Kubernetes

    Carlos Santana

    Carlos Santana argues that a Kubernetes platform should treat agent-generated code as untrusted and provision isolation, credentials, and network policy separately. He describes using kro to compose those controls behind a platform API and shows captures of an Agent Sandbox warm pool assigning a ready pod.

    30 min slot · Any Level · Session

    AI agents and automationSecurity, identity and policy

    Watch this if: you need to give teams a Kubernetes API for agents without giving those agents unrestricted access.

    1. 5:25 Santana describes SPIFFE and SPIRE as a way to identify an agent by URI and associate that identity with a credential across different environments.
    2. 12:14 Santana shows a kro ResourceGraphDefinition and explains how a declarative resource graph can give platform users a custom API without requiring the platform team to write a Go controller.
    3. 19:05 Santana compares gVisor, Kata Containers, and AWS Nitro Sandboxes as different isolation choices for running untrusted agent code.
    4. 21:27 Santana shows captures of a two-pod Agent Sandbox warm pool and says applying a claim assigned a ready pod instead of waiting for a fresh sandbox to start.
    5. 25:48 Santana describes a credential proxy that attaches a credential to an outbound request without handing the underlying secret to the agent, and gives an Agent Substrate example.
