    Agentic Inference at Scale

    Maroon Ayoub, Sean Horgan

    Maroon Ayoub and Sean Horgan describe how llm-d serves agentic sessions, which they say read far more input than they generate, by routing to cached context, offloading KV cache and splitting prefill from decode. They show production examples of zero-downtime router rollouts and flow control, and outline the Agentic Inference SIG's plans for session-level orchestration.

    20 min slot · Level not listed · Session

    AI agents and automationAI inference and serving

    Watch this if: You serve coding agents or other long multi-turn LLM sessions on Kubernetes and care about cache hit rates.

    1. 0:36 Maroon Ayoub says agentic sessions send far more input than output, around a hundred to one, so avoiding recompute unlocks hardware capacity.
    2. 2:46 He describes a production case where prefill compute fell from 16% to 4% while traffic doubled, after fixing how vLLM handled a timestamp Claude Code injects into each turn's system prompt.
    3. 6:26 He explains how the llm-d router balances prefix cache affinity against load-aware routing to avoid hot spots.
    4. 10:44 He shows a production router rollout where the new router loads a state snapshot, takes over traffic and the old one drains with zero errors.
    5. 13:38 Sean Horgan outlines the Agentic Inference SIG's work on orchestrating whole sessions rather than single requests.

    Cloud Native without Limits: Powering the AI Era in the Open

    Chris Aniszczyk, Jonathan Bryce, Rita Zhang, Kevin Cochrane, Robert Nishihara, Justin Boitano, Bassam Tabbara

    The opening speakers say that agents are driving inference demand and describe how cloud providers are contributing fixes from production back to open source. The session includes announcements about KubeRay and OpenShell and a ModelPlane demo that moves an inference deployment between clouds.

    llm-d 1.0 Production-Grade Inference for Cloud-Native AI

    Carlos Costa, Robert Shaw

    The speakers describe llm-d as a modular stack for running model inference on Kubernetes and explain what the release adds for running it in production. In a recorded demo, they compare round-robin traffic with cache-aware routing and show how flow control separates requests by service tier.

    25 min slot · Level not listed · Session

    AI inference and serving

    Watch this if: You run shared model serving infrastructure and want to see how cache-aware routing and request priorities change behavior under load.

    1. 1:44 The speakers frame inference scaling as an orchestration problem involving cache reuse, independent scaling of prefill and decode, and workloads spread across multiple pods.
    2. 3:11 The speakers explain that llm-d builds on Kubernetes interfaces, using an inference gateway for cache-aware routing and LeaderWorkerSet for multi-pod workloads.
    3. 5:50 The speakers describe their 'well-lit paths' as deployable blueprints with benchmark data to help teams start without tuning every part of the stack from scratch.
    4. 13:19 The speakers describe llm-d version 1 as adding a stable API, priority and fairness for competing tenants, and a highly available router with coordinated prefill and decode rollouts.
    5. 17:21 In the recorded demo, the speakers report nearly doubling throughput after enabling cache-aware routing, then show how enabling flow control splits traffic into three queues.
