    Cloud Native Without Limits: What Can AI Agents Do for Us?

    Lin Sun

    Lin Sun uses a live drone photo and a group of Kubernetes-hosted agents to make a short film with the audience. When the workflow hits a rate limit, she shows an agent proposing a pull request for human review and uses distributed traces to see what went wrong.

    12 min slot · Level not listed · Keynote

    AI agents and automation

    Watch this if: you want a live example of agents working across Kubernetes, pull requests, authentication, and distributed tracing.

    1. 1:14 Sun introduces the drone pilot and uses the live flight to capture an image of the audience for the demo.
    2. 2:49 Sun shows how she deploys agents with Argo CD and describes the services that let suspended agents resume when needed.
    3. 7:01 Sun calls on a platform agent to troubleshoot a rate-limit error, then reviews the pull request it opens before approving it.
    4. 12:39 Sun asks the audience for permission to publish the film and explains why the publishing tool requires authentication.
    5. 13:38 Sun uses distributed traces to identify the earlier rate-limit error and show where the successful run spent time generating video.

    From Laptop to Cluster: The Agentic AI Inner Loop on Kubernetes

    Kevin Dubois

    Dubois uses a multiplayer racing game to demonstrate an agentic application with MCP tools and cooperating agents. He explains how he inspects and tests the application locally and what he would monitor and secure when deploying it to Kubernetes.

    30 min slot · Any Level · Session

    AI agents and automationPlatform engineering and developer experience

    Watch this if: you are building an agentic application locally and want practical checks before deploying it to Kubernetes.

    1. 5:50 Dubois connects a coding assistant to the game's MCP server and shows that administrator controls require authentication.
    2. 13:07 He introduces reShapr as an option for exposing selected existing API operations through MCP without rewriting them.
    3. 22:41 He opens the Quarkus developer UI to inspect Kafka game events, AI services, and the MCP tools the game exposes.
    4. 24:34 He shows how a model change led a game agent to choose a different speed multiplier and recommends adding evaluations to the test suite.
    5. 26:13 He recommends checking the health of sub-agents and MCP servers, not just the main application, and measuring latency and token usage.
